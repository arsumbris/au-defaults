# Start here

Turn a corpus of source material into a connected knowledge graph.
You can start with:

- PDFs and documents
- Output from `au-tree-research`
- Other articles, notes or source material

For PDFs and documents, follow [[README::au-ingest#How to use this]] to set up `ingest` and create Markdown source notes.
Keep linked research notes together when copying tree-research output.

Launch an agent with the `au-weave` skills and select [[core-profile::au-writing-style]] to load the writing rules.
Start with `premise` to define what your graph should help you understand and which sources belong.
Then work through your sources with `mine → cut → weave → reweave` and use `tend` to maintain the graph.
