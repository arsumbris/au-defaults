# Start here

This workspace brings together the Ars Umbris packages for building your own au-repo.
You and your agents work in the same local graph.
Alongside the knowledge, you build the guidance and tools that help you work with it.

## Get going

Launch an agent with the [[arscontexta]] profile.
Ask it to use [[init-arscontexta]] to define your workspace's purpose and choose a first task.

Tell your agent what you want to build and start with one useful task.
The packages provide building blocks you combine as the work grows.

See [[packages]] for what each bundled package gives you.

## As it grows

Keep your knowledge and custom guidance in your own repo.
Ask your agent to help you write a guide, create a profile, or build a capability.
Choose the skills, tools and profiles you need in your agent launch.

The optional arscontexta profile supplies [[co-inhabitant]], and [[init-arscontexta]] helps establish a purpose and first step.
